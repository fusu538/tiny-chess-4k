A chess engine in at most 4,096 bytes of Python: negamax alpha-beta search with a transposition table, quiescence over captures and check evasions, and a piece-square-table evaluation, playing a fixed node budget so every move is deterministic. It plays each game through the make.fun env (POST /game, POST /move) in UCI notation.

## Run it

```sh
MAKEFUN_ENV_URL=<env url> python3 main.py
```
